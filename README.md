# Stranger Things Letter Wall

一个复刻《怪奇物语》经典灯墙场景的互动网页。

灵感来自 Will 家里那面写满字母、缠着彩灯的墙。灯光一闪一灭，像是来自另一个世界的讯号。

这个小网页最核心的玩法是手势交互：打开摄像头，用手指在镜头前指向墙上的字母，慢慢拼出想发送的单词；张开手掌，就像把讯号送出去。手机扫码进入同一个房间后，会收到这串来自灯墙的发光文字。

## 怎么玩

打开网页后，你会看到一面字母灯墙。

- 打开摄像头，用手势指向字母，让墙上的灯依次亮起
- 张开手掌，可以触发发送
- 点击 `Connect` 会出现二维码，手机扫码后进入同一个房间
- 电脑发送的文字，会在手机上以发光字体闪烁出现
- 手机端可以切换横屏/竖屏显示，方便把灯墙摆到更合适的位置
- 也可以点击字母或用键盘辅助输入
- `Backspace` 删除上一个字母，`Esc` 清空，`Enter` 发送

## 适合怎么玩

你可以把它当成一个小小的氛围玩具：

- 和朋友互相发送神秘单词
- 把手机当作“异世界接收器”
- 用手势在镜头前慢慢拼出一段只有对方能收到的讯号
- 在派对、拍照、视频里当一个互动背景
- 继续改造成更怪、更电影感、更有故事感的版本

这不是一个正式产品，就是一个做着玩的网页实验。你可以自由发挥，继续加声音、震动、更多灯光节奏、隐藏彩蛋，或者把它改造成属于你自己的奇怪通讯装置。
