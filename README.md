# Stranger Things Letter Wall

一个复刻《怪奇物语》经典灯墙场景的互动网页。

灵感来自 Will 家里那面写满字母、缠着彩灯的墙。灯光一闪一灭，像是来自另一个世界的讯号。你可以在电脑上输入字母，让墙上的灯依次亮起，也可以让手机扫码进入同一个房间，在手机屏幕上看到传来的单词。

## 怎么玩

打开网页后，你会看到一面字母灯墙。

- 点击墙上的字母，可以拼出一句消息
- 用键盘也可以直接输入字母
- `Backspace` 删除上一个字母
- `Esc` 清空当前消息
- `Enter` 发送消息
- 点击 `Connect` 会出现二维码，手机扫码后进入同一个房间
- 电脑发送的文字，会在手机上以发光字体闪烁出现
- 手机端可以切换横屏/竖屏显示，方便把灯墙摆到更合适的位置
- 打开摄像头后，可以尝试用手势指向字母、张开手发送

## 适合怎么玩

你可以把它当成一个小小的氛围玩具：

- 和朋友互相发送神秘单词
- 把手机当作“异世界接收器”
- 在派对、拍照、视频里当一个互动背景
- 继续改造成更怪、更电影感、更有故事感的版本

这不是一个正式产品，就是一个做着玩的网页实验。你可以自由发挥，继续加声音、震动、更多灯光节奏、隐藏彩蛋，或者把它改造成属于你自己的奇怪通讯装置。
